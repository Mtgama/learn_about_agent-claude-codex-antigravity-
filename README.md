## 🇬🇧 English

### About this repository

This repository is a collection of **four practical guidebooks** for working with AI coding agents. Written in Persian, the books take the reader from foundational concepts to advanced, production-ready workflows with **Claude Code**, **OpenAI Codex**, and **Google Antigravity**.

### 📑 The Books

| # | Book | Description |
|---|------|-------------|
| 1 | [**Introduction to AI Agents**](آشنایی%20با%20هاAgent.pdf) | A complete introduction to AI agents — what they are, how they work, types and applications, how to choose the right agent, and how to build and manage projects with them |
| 2 | [**Claude Code**](claude%20code.pdf) | Hands-on guide to Claude and Claude Code — setup, first project, workflow cycle, CLI & Slash commands, security and access control |
| 3 | [**OpenAI Codex**](codexAgent.pdf) | Comprehensive guide to Codex — work environments, standard work cycle, AGENTS.md, advanced capabilities (Skills, Subagents, Plugins, MCP), model selection, and error patterns |
| 4 | [**Google Antigravity**](Antigravity.pdf) | Complete guide to Google Antigravity — agent interaction, task management, code review, MCP integration, security, and best practices |

### 📖 Book Summaries

#### 1. Introduction to AI Agents (`آشنایی با Agent.pdf`)

A foundational introduction that prepares readers for practical use of AI agents. Starting from basic concepts, it gradually covers:

- **What agents are** and why they matter
- **How agents work** — from receiving a request to delivering results, the role of the AI model, goal-setting, planning, tool use, memory & context, and human oversight
- **Types of agents** — coding, research, educational, content creation, automation, subagents, and multi-agent systems
- **Choosing the right agent** — criteria, comparisons, free vs. paid options
- **Getting started** — environment setup, writing tasks, providing context, reviewing outputs
- **Building projects with agents** — from idea to deployment
- **Managing projects** — context management, progress tracking, multi-agent collaboration
- **Limitations, risks & common mistakes** — and how to avoid them
- **Professional principles** — writing precise prompts, evaluating outputs, maintaining control

#### 2. Claude Code (`claude code.pdf`)

A practical guide to working with Claude and Claude Code in software development projects:

- **Introduction to task-oriented AI** — what it is, and how agents differ from simple chatbots
- **Claude & Claude Code** — introduction, capabilities, and applications in software development
- **First project setup** — prerequisites, installation, project initialization, and first request
- **Recommended workflow cycle** — understanding project state, planning, staged execution, testing, review, and human decision-making on commits
- **CLI & Slash commands** — differences, interactive commands, project commands, session management
- **Security & access control** — permissions, file/tool access, command approval, security settings

#### 3. OpenAI Codex (`codexAgent.pdf`)

A comprehensive guide to using Codex safely and effectively in software projects:

- **Introduction to Codex** — what it is, what problems it solves, who it's for, and golden rules
- **Work environments** — desktop app, CLI, Cloud, Worktree, browser, mobile, and voice
- **First project setup** — repo selection, Git status, branch creation, AGENTS.md
- **Standard work cycle** — goal definition, planning, execution, review, testing, and manual commit
- **CLI & Slash commands** — planning, status, reasoning, environment, session, tools, and memory commands
- **Security** — sandbox, approval policies, access levels, computer use, sensitive file management
- **Git & three essential pre-commit checks** — file verification, sensitive file integrity, change size review
- **AGENTS.md & project rules** — role, reading order, suggested content, common mistakes
- **Advanced capabilities** — Skills, Subagents, Plugins, MCP
- **Model selection & reasoning levels**
- **Ready-to-use patterns** — error patterns for problem understanding, environment, dependencies, code, deployment, paths, and context

#### 4. Google Antigravity (`Antigravity.pdf`)

A complete guide to Google's agent-first development environment:

- **Introduction to Google Antigravity** — what it is, core agent capabilities, and use cases
- **Workspace & project setup** — environment, installation, agent panel, editor, and terminal
- **Agent interaction & task cycle** — writing precise requests, planning, execution, code review, testing, and Git commits
- **Core capabilities** — file operations, terminal commands, browser integration, Artifacts, parallel agent execution
- **Customization** — agent settings, model selection, Rules, AGENTS.md, Skills, context management
- **Advanced capabilities** — MCP protocol, service integration, plugins, automation
- **Security & access control** — permissions, sandbox, command review, sensitive file protection
- **Errors, limitations & best practices** — common errors, unwanted changes, output review, golden rules
- **Summary & glossary** — key takeaways and terminology

### 📖 خلاصه کتاب‌ها

#### ۱. آشنایی با ایجنت‌ها (`آشنایی با Agent.pdf`)

مقدمه‌ای پایه‌ای که خواننده را برای استفاده عملی از ایجنت‌های هوش مصنوعی آماده می‌کند. از مفاهیم پایه شروع شده و به‌تدریج موارد زیر را پوشش می‌دهد:

- **ایجنت چیست** و چرا اهمیت دارد
- **ایجنت‌ها چگونه کار می‌کنند** — از دریافت درخواست تا ارائه نتیجه، نقش مدل هوش مصنوعی، هدف‌گذاری، برنامه‌ریزی، استفاده از ابزارها، حافظه و زمینه، و نظارت انسان
- **انواع ایجنت‌ها** — برنامه‌نویسی، پژوهشی، آموزشی، تولید محتوا، اتوماسیون، ایجنت‌های فرعی و سیستم‌های چندایجنتی
- **انتخاب ایجنت مناسب** — معیارها، مقایسه‌ها، گزینه‌های رایگان و پولی
- **شروع کار** — راه‌اندازی محیط، تعریف وظیفه، ارائه زمینه، بررسی خروجی‌ها
- **ساخت پروژه با ایجنت** — از ایده تا استقرار
- **مدیریت پروژه** — مدیریت زمینه، پیگیری پیشرفت، همکاری چندایجنتی
- **محدودیت‌ها، خطرات و اشتباهات رایج** — و راه‌های پیشگیری از آن‌ها
- **اصول حرفه‌ای** — نوشتن پرامپت‌های دقیق، ارزیابی خروجی‌ها، حفظ کنترل

#### ۲. کلاد کد (`claude code.pdf`)

راهنمای عملی کار با کلاد و کلاد کد در پروژه‌های توسعه نرم‌افزار:

- **مقدمه‌ای بر هوش مصنوعی عاملمحور** — چیست و تفاوت ایجنت با چتبات ساده
- **کلاد و کلاد کد** — معرفی، قابلیت‌ها و کاربردها در توسعه نرم‌افزار
- **راه‌اندازی نخستین پروژه** — پیش‌نیازها، نصب، آماده‌سازی پروژه و اجرای نخستین درخواست
- **چرخه کاری پیشنهادی** — شناخت وضعیت پروژه، برنامه‌ریزی، اجرای مرحله‌ای، تست، بازبینی و تصمیم‌گیری انسانی برای Commit
- **دستورهای CLI و Slash** — تفاوت‌ها، دستورهای تعاملی، دستورهای پروژه و مدیریت نشست‌ها
- **امنیت و کنترل دسترسی** — مجوزها، کنترل دسترسی فایل/ابزار، تأیید اجرا و تنظیمات امنیتی

#### ۳. کدکس OpenAI (`codexAgent.pdf`)

راهنمای جامع استفاده ایمن و مؤثر از کدکس در پروژه‌های نرم‌افزاری:

- **آشنایی با کدکس** — چیست، چه مشکلی حل می‌کند، برای چه کسانی مناسب است و اصول طلایی
- **محیط‌های کاری** — اپلیکیشن دسکتاپ، CLI، Cloud، Worktree، مرورگر، موبایل و قابلیت صوتی
- **راه‌اندازی نخستین پروژه** — انتخاب ریشه ریپو، وضعیت Git، ایجاد شاخه و AGENTS.md
- **چرخه استاندارد انجام کار** — تعریف هدف، برنامه‌ریزی، اجرا، بازبینی، تست و commit دستی
- **دستورهای CLI و Slash** — برنامه‌ریزی، وضعیت، استدلال، محیط اجرا، نشست، ابزار و حافظه
- **امنیت** — Sandbox، سیاست‌های تأیید، سطوح دسترسی، Computer Use و مدیریت فایل‌های حساس
- **Git و سه بررسی ضروری پیش از commit** — بررسی فایل تغییرکرده، سلامت فایل حساس و منطقی بودن اندازه تغییر
- **AGENTS.md و قوانین پایدار پروژه** — نقش، ترتیب خواندن، محتوای پیشنهادی و اشتباهات رایج
- **قابلیت‌های پیشرفته** — Skill، Subagent، Plugin و MCP
- **انتخاب مدل و سطح Reasoning**
- **الگوهای آماده** — الگوهای خطا برای درک مسئله، محیط، وابستگی‌ها، کد، استقرار، مسیرها و زمینه

#### ۴. آنتی‌گراویتی گوگل (`Antigravity.pdf`)

راهنمای کامل محیط توسعه agent-first گوگل:

- **آشنایی با Google Antigravity** — چیست، قابلیت‌های اصلی ایجنت و حوزه‌های کاربردی
- **محیط کار و راه‌اندازی** — محیط، نصب، پنل ایجنت، ویرایشگر و ترمینال
- **تعامل با ایجنت و چرخه انجام وظایف** — نوشتن درخواست دقیق، برنامه‌ریزی، اجرا، بازبینی کد، تست و ثبت با Git
- **قابلیت‌های اصلی** — عملیات فایل، دستورات ترمینال، یکپارچه‌سازی مرورگر، Artifacts و اجرای موازی ایجنت‌ها
- **شخصی‌سازی** — تنظیمات ایجنت، انتخاب مدل، Rules، AGENTS.md، Skills و مدیریت زمینه
- **قابلیت‌های پیشرفته** — پروتکل MCP، اتصال سرویس‌ها، افزونه‌ها و خودکارسازی
- **امنیت و کنترل دسترسی** — مجوزها، Sandbox، بررسی دستورات و حفاظت از فایل‌های حساس
- **خطاها، محدودیت‌ها و بهترین روش‌ها** — خطاهای رایج، تغییرات ناخواسته، بررسی خروجی و اصول طلایی
- **جمعبندی و واژهنامه** — نکات کلیدی و اصطلاحات تخصصی
